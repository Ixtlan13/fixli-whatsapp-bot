# Fixli WhatsApp 24/7 GPT Bot

Автономный двуязычный (иврит / русский) WhatsApp-ассистент для сервиса бытовых услуг и перевозок Fixli в Израиле (+972 55-294-7783).

## Возможности
- Работает 24/7 в облаке без необходимости держать включенным компьютер.
- Автоматически распознает язык клиента (иврит / русский) и отвечает на живом языке без машинного перевода.
- Квалифицирует лиды: выясняет задачу (хендимэн или перевозка), город, этаж, наличие лифта, просит фото.
- Дает ориентиры цен Fixli.
- Формирует карточку лида и отправляет Диме в Telegram и/или на личный WhatsApp.
- Веб-страница `/qr` для удобного сканирования QR-кода привязки через смартфон.

## Переменные окружения (.env)
- `PORT=3000`
- `OPENAI_API_KEY`: API ключ OpenAI
- `OPENAI_MODEL`: gpt-4o-mini
- `TELEGRAM_BOT_TOKEN`: токен бота для уведомлений Диме (опционально)
- `TELEGRAM_ADMIN_CHAT_ID`: ID чата Димы в Telegram (опционально)
- `DIMA_PERSONAL_PHONE`: личный номер Димы для пересылки лидов в WhatsApp (опционально)

## Деплой на Railway
1. Создать проект на [Railway.app](https://railway.app).
2. Выбрать Deploy from GitHub repo: `Ixtlan13/fixli-whatsapp-bot`.
3. Добавить Persistent Volume на путь `/app/auth_info_baileys` (для сохранения авторизации).
4. Прописать переменную `OPENAI_API_KEY`.
5. Открыть сгенерированный домен `https://.../qr` и отсканировать QR в WhatsApp.
